# logs — Paso 5 (10 %)

Registro de cada etapa para reconstruir qué ocurrió cada día. Salida en `data/logs/`.

## Campos mínimos
- Identificador de ejecución y etapa
- Inicio, fin, duración y estado
- Enlaces encontrados y anuncios nuevos
- Descargas exitosas, fallidas y pendientes
- Registros agregados, actualizados y sin cambios
- Anuncios únicos y tamaño del almacenamiento consolidado
- Errores y estado del envío del correo

Zona horaria explícita y consistente: `America/Bogota`.
