# data/

| Carpeta | Contenido |
|---|---|
| `diario/enlaces/` | Un archivo de enlaces por día (paso 1) |
| `diario/datos/` | Un archivo de datos por día (paso 1) |
| `consolidada/` | Base consolidada: anuncios únicos, estado reciente, historial (paso 2) |
| `logs/` | Logs de cada ejecución y log consolidado (paso 5) |
| `pruebas/` | Corridas de prueba; **no mezclar** con las evidencias del periodo |

Los datos reales del periodo (16–21 nov 2026) sí se versionan como evidencia; los de prueba no.
